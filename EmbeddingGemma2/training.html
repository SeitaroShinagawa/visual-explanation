2. 学習の仕組み

「何を近づけ、何を遠ざけるか」を決める対照損失、空間を広く使わせるスプレッドアウト正則化、 大きな教師の空間を写し取る埋め込み蒸留、それらを入れ子の次元に効かせる MRL。 そしてこれらをどの順番で、どのモダリティにかけるかという 3 段のカリキュラム(§2.3〜§2.4、§3.2〜§3.3)。

損失の全体像

損失式役割使う段階
対照損失 \(\mathcal{L}_C\)(2)(3)正例を近づけ、ハード・バッチ内・同タワーの負例を遠ざけるテキスト事前 FT(小さな重み)/ ファインチューニング
リストワイズ損失 \(\mathcal{L}_C^{\text{list}}\)(4)順位つき正例リストを Plackett–Luce で学ぶ順位つきデータがあるとき
スプレッドアウト正則化 \(\mathcal{L}_S\)(5)ランダムな 2 点を直交に近づけ、空間を等方的に使わせるファインチューニング
埋め込み蒸留 \(\mathcal{L}_D\)(6)Gemini Embedding 2 の埋め込みに直接合わせるテキスト事前 FT(主)/ マルチモーダル事前 FT(唯一)
MRL—上の損失を 768 / 512 / 256 / 128 次元の部分ベクトルにも適用ファインチューニング

対照損失 — 4 種類の「比べる相手」

論文 式 (2)(3): ハード・バッチ内・同タワー負例つき NCE バッチサイズ \(B\) に対し、 $$\mathcal{L}_C = -\frac{1}{B}\sum_{i=1}^{B}\log\frac{Z_i^{\text{P}}}{Z_i^{\text{P}} + Z_i^{\text{HN}} + Z_i^{\text{IB}} + Z_i^{\text{STN}}}$$ $$Z_i^{\text{P}} = e^{\mathrm{sim}(\mathbf{q}_i, \mathbf{p}_i^{+})/\tau},\qquad Z_i^{\text{HN}} = \sum_{\mathbf{p}_i^{-}} e^{\mathrm{sim}(\mathbf{q}_i, \mathbf{p}_i^{-})/\tau}$$ $$Z_i^{\text{IB}} = \sum_{j=1}^{B}\mathbb{1}_{\text{TN}}(i,j)\,e^{\mathrm{sim}(\mathbf{q}_i, \mathbf{p}_j^{+})/\tau},\qquad Z_i^{\text{STN}} = \sum_{j=1}^{B}\mathbb{1}_{\text{TN}}(i,j)\big(e^{\mathrm{sim}(\mathbf{q}_i, \mathbf{q}_j)/\tau} + e^{\mathrm{sim}(\mathbf{p}_i^{+}, \mathbf{p}_j^{+})/\tau}\big)$$ \(\mathrm{sim}\) はコサイン類似度、\(\tau\) は温度。重複による偽の負例は次のマスクで除外します。 $$\mathbb{1}_{\text{TN}}(i,j) = \begin{cases}0 & \text{if } \mathbf{q}_i = \mathbf{q}_j \text{ or } \mathbf{p}_i^{+} = \mathbf{p}_j^{+}\\ 1 & \text{otherwise}\end{cases}$$
前作から「外した」もの — ハードネス重み付け EmbeddingGemma 1 にはハードネガティブの難しさに応じて重みを変える仕組みがありましたが、本作では外しています。 理由は 2 つ —— “it amplifies noisy or weakly associated positive pairs, especially during early training, and compounds gradient scale imbalances between tasks of different modalities.” マルチモーダル化によってタスク間の勾配スケールがばらつくため、それを増幅する仕組みが害になる、という判断です。

リストワイズ損失 — 順位つき正例を Plackett–Luce で

論文 式 (4) \(P\) 個の順序つき正例 \(\mathbf{p}_{i,1}^{+} \succ \cdots \succ \mathbf{p}_{i,P}^{+}\) を持つクエリについて、 $$\mathcal{L}_C^{\text{list}} = -\frac{1}{BP}\sum_{i=1}^{B}\sum_{r=1}^{P}\log\frac{Z_{i,r}^{\text{P}}}{\sum_{k=r}^{P}Z_{i,k}^{\text{P}} + Z_i^{\text{HN}} + Z_i^{\text{IB}}}$$ $$Z_{i,r}^{\text{P}} = e^{\mathrm{sim}(\mathbf{q}_i, \mathbf{p}_{i,r}^{+})/\tau},\qquad Z_i^{\text{IB}} = \sum_{j=1}^{B}\mathbb{1}_{\text{TN}}(i,j)\Big(\sum_{k=1}^{P}e^{\mathrm{sim}(\mathbf{q}_i, \mathbf{p}_{j,k}^{+})/\tau} + \sum_{\mathbf{p}_j^{-}}e^{\mathrm{sim}(\mathbf{q}_i, \mathbf{p}_j^{-})/\tau}\Big)$$

読み方: 第 \(r\) 位の正例は、自分より下位の正例(\(k \ge r\))とハード・バッチ内負例を相手に softmax を取ります。 「1 位は 2 位以下より上、2 位は 3 位以下より上 …」を順に課す、Xia らの ListMLE [21] の拡張です。 順位データからは三つ組(\(q, p^+, p^-\))も抜き出して \(\mathcal{L}_C\) でも学習します。 さらに、正例と負例の類似度に小さな二乗ヒンジ罰則を足し、 閾値で判定するタスク向けにスコアの絶対値を較正します(式は非掲載)。

スプレッドアウト正則化 — 狭い円錐から球面全体へ

論文 式 (5): GOR の 2 次モーメント項 $$\mathcal{L}_S = \frac{1}{B(B-1)}\sum_{1 \le i \ne j \le B}(\mathbf{q}_i^{\top}\mathbf{q}_j)^2 + \frac{1}{B(B-1)}\sum_{1 \le i \ne j \le B}(\mathbf{p}_i^{+\top}\mathbf{p}_j^{+})^2$$

GOR(Global Orthogonal Regularizer, Zhang+ [22])の発想は、「ランダムな 2 入力の埋め込みが、 球面上で一様にばらまいた 2 点と同じ統計(平均と 2 次モーメント)を持つようにする」こと。 高次元の一様な 2 点はほぼ直交するので、内積の 2 乗を 0 へ押せばよい、というわけです。 前作と同様、2 次モーメント項だけを使います(平均項も十分に目標値へ押されるため)。

埋め込み蒸留 — 教師の「空間そのもの」を写す

論文 式 (6) $$\mathcal{L}_D = \mathcal{L}_D^{\mathbf{q}} + \mathcal{L}_D^{\mathbf{p}^{+}} + \mathcal{L}_D^{\mathbf{p}^{-}},\qquad \mathcal{L}_D^{\mathbf{u}} = \frac{1}{B}\sum_{i=1}^{B}\big\|\mathbf{u}_i - \tilde{\mathbf{u}}_i\big\|_2^2\quad\text{for } \mathbf{u} \in \{\mathbf{q}, \mathbf{p}^{+}, \mathbf{p}^{-}\}$$ \(\tilde{\mathbf{u}}_i\) は入力 \(\mathbf{u}_i\) に対する切り詰めて \(\ell_2\) 正規化した教師の埋め込み (複数のハードネガティブがある場合 \(\mathcal{L}_D^{\mathbf{p}^{-}}\) はその平均)。
  • スコアではなく埋め込みを合わせる —— 従来の蒸留(NV-Retriever [31]・ColBERTv2 [32] など)は教師の「関連度スコア」を真似ていました。 本作は EmbedDistill [30] に倣い、ベクトルそのものを一致させます
  • 射影層を使わず切り詰める —— 教師 Gemini Embedding 2 は 3072 次元ですが、低次元出力をサポートしている(MRL 的に学習されている)ので、 先頭 768 次元を切って正規化するだけで生徒と同じ次元になります。EmbedDistill のような次元変換用の射影層は不要
  • ハードネガティブにも蒸留をかける —— “intuitively serves to transfer the teacher's ability to discriminate between queries and their hard negatives, and empirically does improve performance”
  • 3 項は均等な重みで足します

Matryoshka 表現学習(MRL)— 入れ子の次元

対照・スプレッドアウト・蒸留の各損失を、\(k\) 個の重なり合う部分次元に対して別々に計算して足し合わせます。 こうして学習すると、768 次元ベクトルの先頭 512・256・128 次元だけを取り出してもそのまま埋め込みとして使えます。

⚠️ 擬似コード — 論文 §2.3 の式 (2)(5)(6) と MRL の記述から再構成(公式実装は未公開)
# 論文に実装コードは付随しません。以下は式を手続きに書き下したもので、
# 変数名・構造は本解説による再構成です。温度 τ・損失間の重み・MRL の重みは論文に記載がないため引数のままにしています。
import torch, torch.nn.functional as F

def contrastive(q, p, hn, tau, tn_mask):
    # q, p: [B, d] 単位ベクトル / hn: [B, H, d] / tn_mask: [B, B] (重複=0, 対角=0)
    s_qp = q @ p.T / tau                                  # [B, B] 対角が正例 Z^P, 非対角が in-batch Z^IB
    s_hn = torch.einsum('bd,bhd->bh', q, hn) / tau        # [B, H] Z^HN
    s_qq = q @ q.T / tau                                  # 同タワー (クエリ同士)
    s_pp = p @ p.T / tau                                  # 同タワー (ターゲット同士)
    pos  = s_qp.diagonal()
    neg_mask = torch.where(tn_mask.bool(), 0.0, float('-inf'))
    logits = torch.cat([pos[:, None],                     # 分子
                        s_hn,
                        s_qp + neg_mask,                  # IB
                        s_qq + neg_mask, s_pp + neg_mask],  # STN (同じ分母に入る)
                       dim=1)
    return -(pos - logits.logsumexp(dim=1)).mean()        # 式 (2)

def spread_out(x):                                        # 式 (5) の片側
    B = x.shape[0]
    g = (x @ x.T) ** 2
    return (g.sum() - g.diagonal().sum()) / (B * (B - 1))

def distill(u, u_teacher):                                # 式 (6) の 1 項
    t = F.normalize(u_teacher[:, : u.shape[1]], dim=-1)   # 教師を切り詰めて再正規化
    return ((u - t) ** 2).sum(-1).mean()

def mrl(loss_fn, *embs, dims=(768, 512, 256, 128)):       # MRL: 各部分次元で同じ損失
    return sum(loss_fn(*[F.normalize(e[..., :k], dim=-1) for e in embs]) for k in dims)

学習レシピ — 3 段 + マージ + QAT

全体で約 2.9T トークン。そのうち約 300B がテキスト事前 FT、約 2T がマルチモーダル事前 FT、約 600B がマルチモーダル FT です(§2.4)。 2 つの軸 ——モダリティ(テキスト → マルチモーダル)と目的関数(蒸留 → 対照)——を、ずらして切り替えるのが設計の核心です。

① テキスト事前ファインチューニング

QA・文類似度・コード検索・Web 検索などの大規模・非教師のクエリ–ターゲット対(多言語)で学習します。 大きなバッチで勾配を安定させ、バッチ内負例を増やします。損失はほぼ蒸留のみ(対照損失は小さな重みで併用)。 論文はこの段を 3 通りに意義づけます —— ① 最終的なテキスト品質に重要、② カリキュラム学習の一形態、 ③ 双方向注意の暗黙のウォームアップ(LLM2Vec [37] 的)。さらに LCO [10] を引いて、 テキストでの事前学習が非テキストの埋め込みの識別性も高めることが示されているとも述べます。

② マルチモーダル事前ファインチューニング

画像・音声・動画・文書を含む新しい混合データで続行します。テキスト側のタスクは前作のファインチューニング段のものを含みます。 損失は蒸留だけ —— “to inherit the teacher's ability to map diverse and mixed modalities into a shared semantic space”。 バッチも学習率も大きくし、① の2 倍のステップを回します。

③ マルチモーダルファインチューニング — 教師から離れる

ここで蒸留を完全に対照損失へ置き換え、スプレッドアウト正則化と MRL を加えます。理由は明快です —— “the teacher's embedding space is not optimized for the student's architecture, size, and MRL sub-dimensions.” 3072 次元の巨大な教師の空間を 768 次元の小さな生徒が完全に真似るのは無理があり、 最後は自分の容量に合った空間を自分で作らせる、という発想です。

MLLM でも最近のマルチモーダル埋め込みでも、モダリティエンコーダは凍結するのが一般的でした (Prismatic VLMs [45]・LLaVA [46]・PaLM-E [47]、UEmbed [48]・Omni-Embed-Nemotron [9]・jina-v5-omni [49]・E5-V [4])。 しかし本作では、強力な Gemma 4 視覚エンコーダであっても学習させると Overall で +4.09。 両条件ともテキスト事前 FT のチェックポイントからマルチモーダル事前 FT を回して比較しており、 視覚エンコーダが実験前に更新されていないことを保証しています。 論文は “Analogous gains are likely possible by further training the audio encoder.” と付け加えますが、 実際の最終モデルでは音声エンコーダは凍結のままです。

「凍結」のもう 1 つの動機 — 既存索引との互換性 バックボーンまで凍結する設計(BLIP-2 [52]、jina-v5-omni [49])には、 テキスト埋め込みで作った既存データベースを作り直さずに済む(backfill 不要)という利点があります。 論文はこれを認めつつ、① 埋め込みは別モデルの空間へ翻訳できる(ペアデータや元モデルなしでも [53, 54])、 ② テキストのみのバックボーンを凍結するとマルチモーダル理解が経験的に制限される、の 2 点から、 最強クラスのモデル(LCO [10]・Ovis-Embedding [12])と同様にバックボーンも学習する道を選んでいます(§3.3)。

④ モデルマージ

前作はデータ混合比の違う複数の FT 実行を、Model Soups [40] はハイパーパラメータの違う複数の実行を平均しました。 本作は1 本の FT 軌道上の 2 点(最終チェックポイントと、かなり早い時期のチェックポイント)を重みなしで平均します (SWA [41] 的)。Wortsman+ [42](WiSE-FT:事前学習と FT 後を混ぜる)と同様、 FT で過学習したタスクの劣化を緩和しつつ、FT が効いたタスクはさらに伸ばす、と報告しています。 複数の FT ジョブを回す必要がないのが実務上の利点です。

⑤ 量子化認識学習(QAT)

部位量子化方式QAT
バックボーンint4 ブロック単位(Q4_0)/ int4 チャネル単位(Q4_C)の 2 種あり

前作は QAT を FT 段の中で直接行っていましたが、本作はマージ後の独立した「尾部パッチ」段を設け、 凍結した float チェックポイントから QAT 版を蒸留(かつ初期化)します(Apprentice [44] 的)。 これにより QAT 段が安く済み、float との差が縮まります(特に MTEB English)。結果の数値は推論編の Table 1 で。
