3. 生成の仕組み

テキストは「語彙から選ぶ」、画像・音声は「条件から拡散復元する」。分岐点を順に追います。

まず入力を一本の文脈にする

テキストは tokenizer、画像・音声は modality encoder と input projector を通し、時系列の embedding に組み込みます。過去に生成されたモダリティも同じ形式で再入力できるため、次のターンで参照できます。

自己回帰ループとモダリティ分岐

テキスト生成：通常の causal LM

CoDi-2/inference.py — generation entry point公式コードで確認 ↗
# Conceptual call boundary used by the inference entry point
output = model.generate(
    input_ids=input_ids,
    inputs_embeds=multimodal_embeddings,
    max_new_tokens=max_new_tokens,
)

各 step で LM head の logits から token を選び、EOS まで系列を伸ばします。普通の LLM と違うのは、モダリティ境界を表す token を生成したとき、その周辺の hidden states を後段でも使う点です。

非テキスト生成：hidden state をプロンプトに変換

  1. 生成列から画像または音声の開始・終了を示す区間を検出する。
  2. その位置に対応する最終層 hidden states を選択・集約する。
  3. modality-specific output projector で CoDi の条件空間へ写像する。
  4. ランダム noise から始め、classifier-free guidance を含む反復 denoising を行う。
  5. latent を decoder で画像または waveform に戻す。
