同じ系列の中で、離散 token と連続 feature はどのように共存するのでしょうか。

系列は「場所」、特徴は「内容」

特殊 token はモダリティ区間の境界・生成要求を LLM に知らせます。一方、画像や音声そのものの内容は encoder が得た連続 feature です。つまり特殊 token だけに画像情報が圧縮されているわけではありません。

二つの射影を混同しないinput projector は各 encoder の特徴を LLM の embedding 次元へ運びます。output projector は指定位置の LLM hidden states を diffusion が理解する条件特徴へ戻します。向きが逆です。
