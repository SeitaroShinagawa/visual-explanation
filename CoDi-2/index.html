CoDi-2 図解

テキスト・画像・音声をひと続きの会話として理解し、同じ会話の中へ生成する仕組みを、実装コードと動く図で追います。

CoDi-2 は何を変えたのか

CoDi-2 は、Microsoft Research の composable diffusion 系列を、multimodal interleaved instruction に拡張したモデルです。単に「入力は何でも、出力も何でも」ではなく、文章の途中に画像や音声が挟まる履歴を一つの系列として扱います。

NExT-GPT との読み分けNExT-GPT がモダリティ別の signal token と projector で既成の拡散モデルを呼ぶのに対し、CoDi-2 の中心は、LLM の隠れ状態を生成条件となる連続特徴へ整列させ、CoDi の diffusion decoder に渡すことです。テキストは LLM が離散 token を自己回帰生成し、それ以外は LLM が予測した特徴を条件に diffusion が生成します。
