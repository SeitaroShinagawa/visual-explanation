2. 学習と生成の仕組み

離散トークンの次トークン予測と、連続潜在のflow matching。 数学的にまったく別種の 2 つの目的関数が、 1 本の系列・1 回の順伝播・1 回の逆伝播の中で同時に最適化されます。

2 つの目的関数が同居する

論文 §2.1 の学習目的関数 テキスト: 標準的な自己回帰交差エントロピー \(\mathcal{L}_{\text{LM}}\)。

視覚: フレーム単位の flow matching。 クリーンな潜在 \(z_0\) とノイズ \(\epsilon \sim \mathcal{N}(0, I)\) に対し、 \(t \sim \mathcal{U}[0,1]\) を引いて $$z_t = (1-t)\,\epsilon + t\,z_0$$ を作り、次を最小化します。 $$\mathcal{L}_{\text{flow}} = \mathbb{E}_{t, z_0, \epsilon}\Big[\big\|v_\theta(z_t, t, \cdot) - (z_0 - \epsilon)\big\|_2^2\Big]$$ 結合損失: $$\mathcal{L} = \lambda_{\text{LM}}\mathcal{L}_{\text{LM}} + \lambda_{\text{flow}}\mathcal{L}_{\text{flow}}, \qquad \lambda_{\text{LM}} = 1.0,\ \ \lambda_{\text{flow}} = 3.0$$

式を読み解くポイントは 3 つあります。

  • \(t\) の向き —— \(t=0\) が純ノイズ、\(t=1\) がクリーンです。 拡散モデルの慣例(\(t\) が大きいほどノイズが多い)とは逆向きなので混乱しやすい箇所です
  • 回帰の対象は「速度場」 —— 目標は \(z_0 - \epsilon\)、 つまりノイズからクリーンへ向かう直線の方向ベクトルです。 BAGEL の Rectified Flow と同じ発想で、 NWM の \(\epsilon\) 予測とは別系統
  • \(\lambda_{\text{flow}} = 3.0\) —— 視覚側に3 倍の重みが付いています。 論文はこの値の導出理由を明記していませんが、 §E.2 の「loss centering」の議論から、2 つの損失のスケールが大きく違うことへの 素朴な対処だと読めます
ノイズスケジュールを「ノイズが多い側」へずらす 論文は “We shift the noise schedule towards the noisier end” と述べ、 Esser+ (2024) と RAE の先行研究に従うとしています。

理由は高次元潜在の性質にあります —— SigLIP 2 の潜在は VAE 潜在より次元が高く、 同じノイズ量でも「情報が壊れる度合い」が相対的に小さくなります。 そのため難しい(ノイズの多い)領域を重点的にサンプリングしないと学習が甘くなる。 BAGEL が解像度を上げる際に timestep shift を 1.0 → 4.0 に上げたのと、 動機は同じ方向です。

予測対象 — v 予測と x 予測

上の式は速度場(v)予測ですが、論文はx 予測(クリーンな \(z_0\) を直接予測する)も試します。 そしてどちらが良いかは視覚表現に依存するという、少し意外な結果を報告します。

視覚表現次元x 予測v 予測論文の観察(Figure 20)
RAE(SigLIP 2) 高次元 良い やや劣る 全粒度で x 予測が画像生成に勝ち、言語への影響はほぼ無い

論文の解釈は “x-pred is less stable for low-dimensional representations as expert dimension shrinks, while high-dimensional representations benefit”。 最終構成では RAE + x 予測が採用され、DPG スコアが 0.63 → 0.65 に上がっています。

損失の重みを動的にする — loss centering

\(\lambda_{\text{flow}} = 3.0\) という固定重みには弱点があります —— エンコーダを変えると flow matching 損失の大きさが桁違いに変わるのです。 付録 §E.2 は DINO の centering に着想を得た適応的重み付けを試しています。

論文 Eq. (1)–(2) 各ステップで $$c_{\text{current}} = \alpha \mathcal{L}_{\text{flow}} + (1-\alpha)\mathcal{L}_{\text{LM}}$$ を計算し(\(\alpha \in [0,1]\) が重視度を制御)、EMA で中心を更新 \(c_{\text{target}} \leftarrow \mu\, c_{\text{target}} + (1-\mu)\, c_{\text{current}}\)。 そして重みを $$w_{\text{flow}} = \frac{c_{\text{target}}}{\mathcal{L}_{\text{flow}}}, \qquad w_{\text{LM}} = \frac{c_{\text{target}}}{\mathcal{L}_{\text{LM}}}$$ と置きます。損失が大きいほど重みを小さくするので、 2 つの損失の実効的な寄与が揃います。

生成の仕組み — モダリティを切り替えながら書く

推論時、モデルは離散的な自己回帰生成と連続的な flow matching のあいだを 動的に行き来します。切り替えの合図は <BOI> トークンです。

⚠️ 擬似コード — 論文 §C の記述から再構成(公式実装は未公開)
# 論文に実装コードは付随しません。以下は §C の文章を手続きに書き下したもので、
# 変数名・構造は本解説による再構成です。論文に書かれていない箇所は補っていません。

seq = embed_text(prompt)                    # 系列は 1 本

while not done:
    logits = model(seq)[-1]                 # 語彙ヘッド
    tok = sample(logits)

    if tok == BOI:                          # ← ここがモード切り替え点
        seq.append(BOI)
        z = randn(256, d_latent)            # 純ノイズを 256 個並べる
        for step in range(25):              # 25-step Euler サンプラ
            t = step / 25
            v = model(seq + z)              # 連続線形ヘッドが速度場を返す
            v = cfg(v, guidance_scale=3.0)  # classifier-free guidance
            z = z + v * (1 / 25)            # Euler 更新
        seq.append(z)
        seq.append(EOI)                     # テキスト生成へ戻る
    else:
        seq.append(tok)

pixels = frozen_decoder(z)                  # 潜在 → 画素(RAE の既製復号器)

この章のまとめ

学習と生成を 4 点で
  1. 損失は 2 本を足すだけ —— 交差エントロピー(重み 1.0)+ flow matching(重み 3.0)。 1 回の順伝播・逆伝播で同時に最適化する
  2. ノイズはフレームごとに独立に載る。 スケジュールは高次元潜在に合わせて「ノイズが多い側」へずらす
  3. 予測対象は表現に依存する —— 高次元(RAE)なら x 予測、低次元(VAE)なら v 予測が安定
  4. 推論は <BOI> の出現で切り替わる。 25 step の Euler で描いて <EOI> を置き、テキストへ戻る

次章では、この仕掛けで学習したモデルをどう測り、何が分かったのか —— 7 つの評価指標と、視覚表現・データ・世界モデルの 3 つの実験群を見ていきます。
