# Beyond Language Modeling 図解 — トピック概要と作成プロセスの記録

## このトピックについて

*Beyond Language Modeling: An Exploration of Multimodal Pretraining*
(Tong, Fan, Nguyen+, ICML 2026 / PMLR 306 / [arXiv:2603.03276](https://arxiv.org/abs/2603.03276))は、
FAIR at Meta・NYU による **統一マルチモーダル事前学習の統制実験**。
本シリーズで先に扱った NExT-GPT / CoDi-2 / BAGEL / NWM がいずれも「新しいモデルの提案」だったのに対し、
本作は **モデルを提案しない** —— 言語モデルからの初期化を捨ててゼロから学習し直し、
1 度に 1 変数だけを変えることで **設計空間そのものの地図**を描いた論文である。
本解説は、その **5 つの設計軸(視覚表現・データ・世界モデル・アーキテクチャ・スケーリング)** を、
論文の数式・図表の引用とアニメーション図解で読み解く 5 ページ構成の日本語解説である。

| ページ | 内容 |
|---|---|
| `index.html` | 研究背景(プラトンの洞窟 / テキストの枯渇)/ 関連研究の 3 系譜 / 問題設定(5 つの軸)/ 全体アーキテクチャのアニメ図 / 本シリーズ他モデルとの対比 / 章立て |

| `training.html` | 2 つの損失(CE + flow matching)、ノイズスケジュール、v 予測 vs x 予測、loss centering、4 種のデータ、ハイパーパラメータ、モーダル切り替え推論 |

## 本シリーズ初の「コードなし」トピックとしての方針

他トピックはすべて公式実装をクローンして行番号付きで引用してきたが、本トピックではそれができない。
代わりに次の 3 つを使い、**論文に書かれていないことは補わない**方針で書いた。

1. **論文の数式をそのまま**(flow matching、loss centering、特化スコア、スケーリング則)
2. **論文の表・図の数値を再掲**(Table 1/2/3/4/5/6、Figure 7/8/19/20/21/26 など)
3. **擬似コード**(モーダル切り替え推論のみ)。必ず `⚠️ 擬似コード — 論文 §C の記述から再構成` と明記

また、図の一部は棒グラフのみで数表がないため(Figure 2/3/4/5/6 など)、
**本文が明示した順序関係**と、**表・本文に数値がある箇所**だけを転記した。
該当箇所にはページ上でその旨を注記している。

## 本シリーズの他トピックとの交差点

本作は、シリーズで先に読んだ 2 本を名指しで扱う。

| 相手 | 本作での扱い | 該当箇所 |
|---|---|---|
| **BAGEL** | **2 か所で否定される** — ① 二重エンコーダ(SigLIP 2 + VAE)は単一 SigLIP 2 に負ける(§3・§6.3)、② MoT による深い分離は MoE に負ける(§6.3) | `architecture.html#ffn` / `experiments.html#repr` |
| **NWM** | **土台として使われる** — データ・CEM 計画・ATE / RPE をそのまま借り、「専用モデルなしで同じことができるか」を検証(§5)。行動は専用ベクトルではなく**テキスト文字列**として書く | `experiments.html#world` |

なお §5 は **NWM より強いとは主張していない**(規模も評価対象も揃っていない)。
主張は「世界モデル能力の出どころは専用データではない」という因果に関するもの。この点はページ上でも明記した。

## このトピックの読みどころ(調査で拾った論点)

1. **λ_flow = 3.0 の非対称な重み** — 論文は導出理由を明記しない。付録 §E.2 の loss centering の議論から、
   2 つの損失のスケール差への素朴な対処と読める。
2. **loss centering は「試したが採らなかった」選択肢** — Table 4 を素直に読むと
   **生成が良くなり言語が悪くなるトレードオフ**(SigLIP 2 で DPG +0.042 / PPL +0.30)。
   §F.1 の既定は固定重みのままなので、本文の構成には採用されていない。
3. **x 予測 vs v 予測は視覚表現に依存する** — 高次元(RAE)なら x 予測、低次元(VAE)なら v 予測。
   VAE + x 予測は粒度を上げるとテキスト PPL が急上昇する。
4. **CFG の扱いが NWM と逆** — NWM には条件ドロップアウトが無かった(行動条件は忠実さが要るため)。
   本作は 10% のドロップアウトを入れ推論時に CFG=3.0 をかける(T2I の忠実さを強めたいため)。
5. **粒度の飽和点がモダリティで違う** — 視覚は G=4、言語は G=16。
   §7 の「言語はパラメータ飢餓・視覚はデータ飢餓」の**ミクロな現れ**として読める。
6. **VQA での事前学習の恩恵がエンコーダで桁違い** — SigLIP 2 +12.5 に対し SD-VAE +0.2、生ピクセルは −0.2。
   WISE(世界知識)で意味エンコーダが VAE を 3〜4 倍上回るのと同じ構図。
7. **拡散 timestep はフレームごとに独立** — NWM が 1 サンプル 1 timestep だったのと対照的。
8. **注意マスクに BAGEL の 3 つ目のモード(noise は他から不可視)が無い** — フレーム単位の
   block-wise causal だけで済ませている。論文は理由を書いていないので、ページ上でも推測であることを明示した。
9. **interleaved データを使っていない**(§A の自己申告) — BAGEL が「複雑な編集能力の源泉」と
   主張していたデータ種別がまるごと欠けている。
