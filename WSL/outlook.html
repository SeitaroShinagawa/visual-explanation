重み空間の手法は、INR・メタ学習・継続学習・連合学習・NAS などでどう使われているのか(§5)。 そして、大規模モデルへの拡張と安全性という 2 つの壁を前に、この分野はどこへ向かうのか(§7)。

未解決問題(§7)

“Despite rapid progress, Weight Space Learning remains in its early stages.” §7 は 3 つの研究方向を挙げています。

§7.1 重み空間を「第一級の学習ドメイン」に

現状への批判 “Many current successes of WSL appear in INRs, where signals are encoded directly into weights. However, these approaches typically treat weights as containers for data, rather than as a domain with its own geometry and semantics.”

必要なのは 2 つです。幾何的・関数的な基盤 —— 対称性と冗長性が作る大きな同値類を商構造で形式化し、 意味のある距離を定義すること(過剰パラメータ化のため関数的な変化はしばしば低次元部分空間に乗っている、という観察も手がかりになる)。 そして汎用な重み空間学習器 —— “A key open question is whether a structure-aware yet architecture-agnostic learner can operate directly on raw model weights.” その候補としてサーベイは LoRA を挙げます: “Because LoRA represents weights through a compact linear transformation, it naturally exhibits strong symmetry properties and aligns well with weight space generation paradigms.”

§7.2 大規模モデルへのスケーリング

“the input size of weight space grows dramatically with model depth and width, coupled with complex symmetry constraints and inter-layer dependencies.” 3 つの方向が挙げられています。

  • モジュール的・階層的処理: 大規模モデルは機能の少し違う同じモジュール(注意ブロック・FFN)の繰り返し。 “can we modulate an entire large-scale model through shared bases plus layer-specific tokens?”
  • 微調整モジュール: 重み生成は既存部品の組み合わせ(compositional generation)に近く、新しい知識を持ち込みにくい [Wiedemer+ 2023, Zeng+ 2025]。 アダプタ・プレフィックス・低ランク変換を生成すれば、基盤モデルの豊かな事前知識を活用した「知識拡張型の合成」になる
  • 圧縮と近似: 既存の潜在符号化手法の多くは重み空間の構造的性質を無視している。 対称性を割った部分空間(LoRA に似た、関数に効く重みが少ない空間)で近似する

§7.3 重み空間操作の頑健性と安全性

“Most existing works prioritize performance and efficiency, leaving security largely unexplored.” WSL では重みそのものが主要なデータモダリティになるため、敵対的攻撃も入力レベルとは根本的に異なる形をとります。

  • 制御可能な重み生成: 生成パイプラインは意図した機能の保証なしに重みを出すことが多く、有害・予測不能な振る舞いのリスクがある。 タスク記述・ドメイン制約・安全規則を生成に統合し、“shift WSL from opaque inner-loop adaptation to transparent, reliable weight synthesis”
  • 攻撃の検知と防御: “malicious edits or injected subspaces can compromise model integrity without altering the original data.” 検知(異常指標・埋め込みベースのプローブで怪しい重みパターンや軌跡を特定 [Shor+ 2025])と、 防御(対称性を考慮した射影・再学習不要の可逆編集)の 2 面
解説者の考察 — 3 つの問題はつながっている 評価編で見た「評価指標の欠如」も含めると、未解決問題は 1 本の鎖として読めます。 大規模化のためには全重みではなく LoRA のような部分空間を扱いたい(§7.2)→ その部分空間を構造をまたいで共通に扱えれば汎用学習器になる(§7.1)→ しかし重みを直接生成・編集できるようになるほど、出てきた重みが何をするかを保証・監査する手段が必要になる(§7.3)→ その監査には、タスク性能だけでなく対称性の保存や機能的性質を測る評価が要る(§3.3, §4.3)。 WSR(重みを見て振る舞いを予測する)が、WSG の安全性を担保する道具になる —— という循環が、この分野の次の数年の姿かもしれません。

なお、汎用 LLM に重みを読ませて監査する(“auditing without evaluation”)という別のアプローチも現れています(→ 発展編)。

全体まとめ

サーベイの結論(§8) “Weight space learning reframes neural networks not merely as function approximators trained on data, but as structured objects inhabiting a rich and informative parameter space. […] we hope this survey helps unify ongoing research and encourages the community to view neural networks in a new light: not only as functions we train, but as entities we can analyze, represent, and create directly in weight space.”
章一言でいうと鍵になる式
1. 理解 (WSU)違う重みが同じ関数になる —— 対称性が重み空間を同値類に分ける\(f(\rho_{in}(\theta); x) = f(\theta; x)\)
2. 表現 (WSR)その対称性を尊重して、重みをデータなしで推論できる埋め込みに写す\(z = \phi(\theta),\ \hat y = \psi(z)\)
3. 生成 (WSG)タスク損失(ハイパーネット)か zoo の分布(生成モデル)から、重みを直接作る\(\theta = H(x)\) / \(W \sim p_\phi(W)\)
4. 評価model zoo が土台。だがタスク性能以外を測る標準指標はまだない—
5. 応用・課題内側ループを「重みの生成」で置き換える流れが各分野で進行中。壁は大規模化と安全性—
6. 発展: WSP専用のメタモデルを学習せず、汎用 LLM が推論で重みを読み・直し・書く(サーベイ後の 2026 年 11 月のブログ)\(\tilde\theta = \theta + \Delta\)(Δ を推論で決める)
